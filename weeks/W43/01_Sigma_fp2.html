Sigma fp2

Sigma keeps the fp2's smallest-full-frame claim intact by turning hardware into the interface: a physical STILL/CINE switch, a dedicated Color button and 1/4-20 mounts across the chassis replace menu depth with choices a thumb can find without looking.

01 · Design Highlights

Physical controls replace menu-diving on this body

Two-hand grip test · amateurphotographer.com
Diamond-knurled grip

Texture replaces leatherette for grip

Sigma swaps the fp's leatherette for a diamond-knurled texture across the back and part of the front, paired with a small raised thumb hook. Reviewers found the actual hold less forgiving than the surfacing suggests — hard square edges still pinch fingers without an accessory grip attached.

1/4-20 attachment points · petapixel.com
Modular mount points

Chassis becomes a rigging platform

A row of 1/4-20 threaded inserts runs across the fp2's strap lugs and base, turning the shrunken chassis into attachment points rather than fixed ornamentation. The approach treats the body as a modular platform: cages, handles or monitors mount directly, without redesigning the camera's own surfacing for every accessory.

Top-plate controls · petapixel.com
Physical mode switch

A switch states intent before menus do

A dedicated top-plate switch flips the fp2 between STILL and CINE modes, each loading its own control layout and color-mode defaults instead of a shared menu. A separate red record button sits beside it, giving the one consistently colored control on an otherwise black, achromatic body.

Official product photo · petapixel.com
Proportion & assembly

Small body, in-house milled precision

At 112.8 by 69.9 by 41.8mm, the fp2 keeps Sigma's smallest-full-frame proportions while carrying a stacked sensor the original fp lacked. Sigma mills and finishes the magnesium chassis in-house at its Aizu factory, a response to tightening tolerance demands that keeps seams flush on such a compressed silhouette.

02 · Technology / Product Architecture

Engineering choices reshape storage and finder habits

Sensor architecture note · petapixel.com
Partially-stacked sensor

Faster readout, not just resolution

The fp2's 24.5MP sensor is partially stacked, a structural change from the original fp's standard CMOS layout. Faster readout reduces rolling-shutter skew during handheld video pans and supports quicker continuous bursts, so the architecture upgrade shows up as fewer distorted verticals rather than a pixel-count headline.

Storage options · petapixel.com
Single-slot storage logic

One SD slot, a 70GB backstop

Rather than dual card slots, the fp2 pairs one UHS-II SD slot with 70GB of built-in storage that keeps recording when a card fills or is missing. It trades the redundancy pros expect for a fallback that treats internal memory, not a second card, as the safety net.

EVF-21 in use · petapixel.com
Add-on viewfinder

An EVF that attaches, not embeds

The EVF-21 clips onto a side USB-C port rather than living inside the body, a modular choice that keeps the base fp2 pocketable. Reviewers found the payoff uneven: eye-level framing returns, but the finder sits bulky and off-axis compared with a built-in unit, trading compactness for an awkward add-on silhouette.

HU-21 hot shoe unit · petapixel.com
Cross-brand hot shoe

A hot shoe shared across brands

The optional HU-21 adds a hot shoe with a flash-communication terminal matching OM SYSTEM and Panasonic LUMIX, and paired with it the fp2 records 32-bit float audio. The add-on shoe keeps the plain top plate intact for users who never need flash or shotgun-mic triggering.

03 · Aesthetic Analysis

Interface details carry as much design weight

Quick menu and Color/Mode buttons · amateurphotographer.com
Dedicated hardware access

Thirteen looks, one physical button

A dedicated Color button sits beside Mode at the bottom edge, while the Quick Menu overlays ISO and white balance directly on the live image. Each control reaches its setting in one press, so visual identity and exposure choices happen at eye level instead of inside a nested picture-profile menu.

Rear control layout · amateurphotographer.com
Control-cluster hierarchy

Two dials carry the information load

The rear three-quarter view shows a body still dense with buttons and two large dials, not a touchscreen-first layout. That density reflects a deliberate hierarchy: exposure and focus adjustments stay on dials the thumb finds by feel, leaving the touchscreen for framing and menu navigation instead.

Tilting rear screen · amateurphotographer.com
Articulating screen geometry

A hinge changes the shooting silhouette

Tilting the rear screen up to 90 degrees turns the fp2 into a waist-level finder, changing the working silhouette without adding any control. The same panel folds down about 45 degrees for overhead framing, so one hinge covers postures a dedicated finder would otherwise need separate hardware to support.

Side connector cluster · petapixel.com
Labeled connector cluster

Finish and icons sort the ports

The side panel groups a gold-plated contact-pin array for accessories next to a 10G USB-C port, full HDMI, a tripod socket and a 3.5mm jack. The gold finish gives users a visual cue for which port expects a cable and which expects a bolt-on accessory.

05 · What Zebra Can Apply

Turn fp2 hardware cues into Zebra sketches

Reference for switch states before menus do01

Switch states before menus do

Sigma's top-plate switch commits to STILL or CINE before any menu opens. Sketch a physical state switch for Zebra devices with two dominant workflows, and test whether operators trust a flip over a software toggle.

Reference for thread mounts for task rigs02

Thread mounts for task rigs

Strap lugs and the base share one 1/4-20 thread, so a single accessory family covers carrying and rigging. Evaluate matching thread points on handheld scanners, letting teams bolt on lights or brackets without custom adapters.

Reference for make the finder an add-on03

Make the finder an add-on

The EVF-21 attaches over USB-C only when eye-level framing is needed, keeping the base unit flat otherwise. Prototype optional viewfinders as bolt-on modules for Zebra handhelds, then weigh added bulk against a sealed, fixed alternative.

Reference for give modes their own button04

Give modes their own button

Dedicated Color and Mode buttons sit beside playback, each a press away instead of buried in a settings tree. Prototype hardware shortcuts for settings operators change most, then time completion against the existing menu path.

06 · Key Takeaway

A compact body still needs a hand to match it.

Sigma's fp2 proves that shrinking a full-frame body doesn't remove the need for physical interface decisions — a mode switch, a Color button and a grid of accessory threads do work a touchscreen menu can't do as quickly. For Zebra, the transferable lesson is to audit which functions deserve a dedicated control before defaulting every setting into software, especially where gloved or one-handed operation makes menu navigation a liability.
